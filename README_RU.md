# HAS VPN — стартовый Flutter-прототип

Этот архив содержит начальный интерфейс Android/iOS на Flutter: главный экран, список стран, настройки и экран аккаунта.

## Важно
Это **не рабочий VPN** и не готовый APK/IPA. Переключатель соединения демонстрационный. Вход/регистрация и подписки — только макеты, данные не отправляются и не сохраняются. Не используйте прототип для защиты реального трафика.

## Как запустить
1. Установите Flutter SDK и Android Studio. Для iOS-сборки нужен Mac с Xcode.
2. Распакуйте архив.
3. В папке проекта выполните:
   ```bash
   flutter pub get
   flutter run
   ```
4. Android APK для тестирования:
   ```bash
   flutter build apk --debug
   ```
   Для публикации Google Play обычно нужен подписанный App Bundle:
   ```bash
   flutter build appbundle --release
   ```
5. Для iOS на Mac:
   ```bash
   flutter build ios --release
   ```
   Затем настройте подпись в Xcode и отправьте сборку через App Store Connect.

## Следующие этапы для реального сервиса
1. Арендовать VPS в выбранных регионах и настроить WireGuard.
2. Сделать backend для пользователей, выдачи/отзыва конфигураций, лимитов и учёта пробного периода.
3. Интегрировать VPN-туннель в Android и iOS (Android VPNService; iOS Network Extension / Packet Tunnel Provider). Это требует нативной настройки и проверки.
4. Добавить безопасную аутентификацию, хранение секретов и восстановление доступа.
5. Подключить подписки через Google Play Billing и Apple In-App Purchase, проверить правила магазинов.
6. Подготовить политику конфиденциальности, раскрытие сбора данных, тесты утечек и модерацию.

## Архитектурная рекомендация
Flutter для общего UI; WireGuard как VPN-протокол; небольшой backend (например, Go) для аккаунтов и управления конфигурациями. Не храните приватные ключи сервера в мобильном приложении.
